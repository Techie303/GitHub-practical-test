# Premkumar Gaikwad — Personal Portfolio

A simple, responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop and mobile
- Light / Dark theme toggle (saved in `localStorage`)
- Interactive project category filter
- Smooth scroll navigation with active section highlighting
- Contact form with client-side validation
- Graceful initials avatar fallback when `img.png` is not added yet

## Getting Started
Open `index.html` directly in your browser, or run a local server:

```bash
python3 -m http.server 8000
```

## Customization
- **Profile Photo**: Add an `img.png` file in the project root — it will automatically appear in the hero avatar.
- **Content & Links**: Edit `index.html` to update your bio, skills, projects, and social links.
- **Colors**: Adjust the CSS custom properties in `:root` inside `style.css`.
